# 체크리스트

상태: `[ ]` 대기, `[~]` 진행 중, `[o]` 완료, `[!]` 일시 우회. 우회에는 명시적인 이유가 필요하며 우회는
완료가 아니다. 항목에 원인과 재시도 조건을 기록하고, 조건이 충족되면 허가를 기다리지 않고 재개한다.
감사는 `[!]` 항목과 그 기록에만 하며 관련 없는 전체 테스트를 반복하지 않는다. 절차는
[AGENTS.ko.md](../AGENTS.ko.md)를 따른다. 각 항목은 의존과 완료 증거를 적는다.

## 요구 사항

- Rust 프로세스 하나가 번들링과 렌더링을 한다. 빌드 시점과 렌더 시점에 Node 프로세스를 실행하지 않는다. 빌드
  전에 `npm ci`가 패키지를 설치한다.
- 렌더 호출은 외부 함수 경계를 넘지 않는다. 호출자는 Rust이며 라이브러리를 직접 호출한다.
- 번들은 V8 isolate마다 한 번 적재·컴파일하며, 호출마다 보내거나 비교하지 않는다.
- props는 호출마다 한 번 V8 값으로 들어가고, 결과는 두 번째 JSON 왕복 없이 바이트로 나온다.
- 컨텍스트 초기화는 전역 상태를 다시 만들지 않고 스냅샷에서 복원한다.
- 첫 소비자가 필요로 하는 것: 클라이언트 번들 하나로 렌더마다 SSR 또는 CSR 선택, hydration을 위한 렌더 상태 입력과
  출력, 정적 CSR 셸, 빌드 공개 파일의 디렉터리 게시, 빌드 파일 제공, 대기열을 가진 제한된 풀, 실행 중인
  스크립트를 종료하는 렌더 타임아웃, 운영체제 난수.
