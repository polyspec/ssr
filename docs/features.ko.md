# 지원 기능

[English](features.md).

`features.json`은 실행 가능한 테스트로 검증한 기능을 기록한다. 각 항목은 고유한 `name`,
`supported: true`, 정확한 Cargo 패키지·테스트 바이너리·테스트 사례를 지정하는 `test` 객체를 가진다.
검사기는 선언한 모든 사례를 정확한 이름으로 실행하고 각 명령에 시간 제한을 적용하며 일치하는
테스트가 없으면 오류를 반환한다. 빌드 성공이나 소스 검사만으로 지원을 인정하지 않는다. 사례가
실패하거나 시간 초과하면 기능 검사도 실패한다.
