# 테스트 소유 위치

`tools/test-ownership.json`은 다른 워크스페이스 크레이트가 의존하는 모든 크레이트의 동작을 선언한다:
페이지, 빌드, 프로세스, 런타임, nonce, React·Svelte·vanilla 어댑터. 선언된 동작이 없는 의존성은 실패한다. 각 동작은 소유 크레이트
루트의 공개 이름을 해당 크레이트의 통합 테스트 하나와 각 소비 크레이트의 실제 사용 테스트 하나에
대응시킨다. 선언된 소유 크레이트의 모든 공개 루트 이름은 정확히 한 동작에 속한다. 선언에는 크레이트,
통합 테스트 대상, 정확한 테스트 함수가 들어간다. 파일 이름만으로는 실행할 사례를 식별할 수 없다.

`tools/test_ownership.py`는 개발 의존성을 포함해 소스·통합 테스트·예제·벤치마크의 Rust import와
완전 경로 참조에서 소비자를 계산한다. 워크스페이스 메타데이터의 의존성 이름과 변경된 의존성 이름을
대조한다. 같은 크레이트의 한 동작에 의존한다고 다른 동작의 테스트를 요구하지 않는다. 주석과 문자열은
import로 계산하지 않는다. 그룹 import와 기호 이름 변경을 지원하며, 선언된 소유자의 wildcard import와
크레이트 별칭은 공개 루트 이름을 식별하지 않으므로 오류다. 공개 이름 선언 누락·중복, 인식하지 못한
소유자 export, 소비자 누락, 실제 소스 사용이 없는 소비자 선언은 실패한다. 지정한 함수가 해당
크레이트의 비어 있지 않은 테스트인지 확인한다. 그 뒤 `cargo nextest run --workspace --no-run`으로
워크스페이스 테스트를 한 번 빌드하고, 지정한 테스트 전체를 그 빌드에서 `cargo nextest` 실행 한 번으로
실행한다. 패키지마다 따로 실행하면 그 패키지만으로 feature를 계산해 공유 크레이트를 feature 조합마다 다시
컴파일한다. 워크스페이스 빌드는 뒤의 워크스페이스 테스트 묶음이 쓰는 빌드이기도 하다. 누락,
잘못된 위치, 빈 사례, 실패, 무시된 사례와 시간 초과는 오류다. 검사기는 각 사례와 결과를 보고한다.
`make check`는 패키지 설치 뒤 워크스페이스 테스트 묶음 전에 이 검사를 실행한다. 이 검사는 테스트
실행과 위치를 확인하며, 지정한 테스트는 자기 크레이트에서 동작의 입력과 출력을 검증한다.

검사기는 `cargo metadata`로 워크스페이스 metadata를 읽고, 이를 경과 시간과 함께 한 단계로
보고하며, 시간 제한 없이 종료 코드로 판정한다. Cargo 진행과 오류는 도착하는 대로 표준 오류로
나간다. Cargo 출력은 도착 즉시 전달한다. 컴파일 전체 시간 제한은 두지 않으며 nextest가 각 테스트의
설정된 기한을 적용한다. 실행기가 중단되면 Cargo 프로세스 그룹을 종료하고 하위 프로세스를 기다린다.
정확히 선언한 사례의 통과 결과가 없으면 종료 코드가 0이어도 실패다. 각 사례의 결과는 nextest의 기계용 보고
(`--message-format-version 0.1`의 `--message-format libtest-json`)에서 읽고, nextest version마다 문구가 다른 사람용
출력에서는 읽지 않는다. feature 검사(`tools/check_features.py`)도 같은 방식으로 사례를 읽는다.

`tools/test-owners.json`은 추적되는 모든 파일을 그 소유 테스트의 명령에 대응시킨다: Git 경로 패턴과
Python 테스트 모듈, 워크스페이스 패키지와 테스트 대상, make target, 추적되는 도구를 가리키는 테스트 명령이다.
`tools/check.py`가 실행하는 `python3 -m tools.owning_tests check`는 소유 테스트가 없는 추적 파일, 추적 파일을
가리키지 않는 패턴, 존재하지 않는 테스트를 가리키는 명령에서 실패한다. `python3 -m tools.owning_tests select`는
`HEAD`와 비교해 바뀐 파일의 소유 테스트 명령을 한 번씩 출력하고, 소유자가 없는 바뀐 파일에서 실패한다. 지운 파일은
바뀐 파일이 아니다. 이것이
커밋 전에 실행할 Red·Green 테스트다.
