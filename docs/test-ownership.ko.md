# 테스트 소유 위치

`tools/test-ownership.json`은 공유 페이지·빌드 동작을 선언한다. 각 동작은 소유 크레이트의 통합
테스트 하나와 개발 의존성을 포함해 소유 크레이트에 직접 의존하는 모든 크레이트의 실제 사용 테스트
하나씩을 지정한다. 선언에는 크레이트, 통합 테스트 대상, 정확한 테스트 함수가 들어간다. 파일 이름만으로는
실행할 사례를 식별할 수 없다.

`tools/test_ownership.py`는 각 소비자 집합을 워크스페이스 매니페스트와 대조하고, 지정한 함수가
해당 크레이트의 비어 있지 않은 테스트인지 확인한 뒤 `cargo nextest`로 각 테스트를 실행한다. 누락,
잘못된 위치, 빈 사례, 실패, 무시된 사례와 시간 초과는 오류다. 검사기는 각 사례와 결과를 보고한다.
`make check`는 패키지 설치 뒤 워크스페이스 테스트 묶음 전에 이 검사를 실행한다. 이 검사는 테스트
실행과 위치를 확인하며, 지정한 테스트는 자기 크레이트에서 동작의 입력과 출력을 검증한다.
