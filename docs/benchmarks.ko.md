# 렌더 벤치마크

`make bench`는 16개 워커의 스냅샷 런타임에서 고정 SSR 페이지 하나를 렌더한다. 각 호출은 HTML과
상태를 검사한다. 동시 호출 1, 4, 16에서 호출자마다 128번 실행하며 렌더 오류, 표본 누락, 결과 변경,
한도 초과 시 실패한다. 빌드의 제한 시간은 30분이고 측정 실행의 제한 시간은 120초다. 호출 경과 시간은
`Pool::render_with_metrics` 직전부터 반환 직후까지다. 처리량은 시나리오의 전체 완료 호출 수를
전체 경과 시간으로 나눈 값이며, p50과 p99는 모든 호출 시간의 최근접 순위를 사용한다. 컨텍스트
초기화 시간은 V8 컨텍스트 생성 구간이다. 메모리는 그 생성 전후의 현재 V8 힙 바이트 변화이며
프로세스 상주 메모리가 아니다. 명령은 관측한 최대 변화를 보고한다.

다음 결과는 2026-09-26에 macOS 26.6.2, Apple M3 Pro, 메모리 36 GiB, Rust 1.98.1,
Cargo 개발 프로필과 검증된 V8 release 소스 archive에서 측정했다. V8 빌드는 별도의 포인터 cage와 외부 코드 공간을
사용한다. 호출 지연에는 워커 통신, JSON 해석, 결과 검사가 포함된다.
번들 컴파일과 HTTP 전송은 포함되지 않는다.

| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 128 | 5,339.1 | 0.179 | 0.249 | 0.160 | 0.204 | 104,088 |
| 4 | 512 | 15,582.5 | 0.195 | 0.486 | 0.167 | 0.408 | 104,312 |
| 16 | 2,048 | 22,100.2 | 0.666 | 1.835 | 0.195 | 1.173 | 104,420 |

유지되는 벤치마크는 시나리오마다 다음 한도를 적용한다. 이 한도는 호스트의 동시 작업을
감안하면서도 측정 결과보다 성능이 크게 저하되면 실패하도록 설정했다.
